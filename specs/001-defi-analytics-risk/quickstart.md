# Quickstart: Solana DeFi Analytics & Risk Management

This guide walks through setting up the tool, running the dashboard, and verifying key features.

## Prerequisites

- Python 3.11 or higher
- A Solana RPC endpoint (Helius free tier works)
- (Optional) Telegram bot token or Discord webhook for alerts

## Setup

1. **Clone the repository** (if not already done):
   ```bash
   git clone <your-repo-url>
   cd <project-root>
   ```

2. **Create a virtual environment and install dependencies**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

   (We'll generate `requirements.txt` later; for now, install the main libraries:
   `aiohttp`, `solana`, `pandas`, `numpy`, `streamlit`, `python-dotenv`, `pyyaml`, `pytest`, `pytest-asyncio`.)

3. **Create a configuration file**:
   Copy `.config.yaml.example` to `.config.yaml` (we'll provide one) and edit:
   ```yaml
   rpc_endpoint: "https://api.mainnet-beta.solana.com"  # or your Helius URL
   polling_interval_sec: 15
   risk_window_days: 30
   portfolio_assets:
     - "So11111111111111111111111111111111111111112"  # SOL
     - "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"  # USDC
   alert_channels:
     telegram: true
     discord: false
   ```

4. **Set up environment variables for alerts**:
   Create a `.env` file:
   ```
   TELEGRAM_WEBHOOK_URL=https://api.telegram.org/bot<YOUR_BOT_TOKEN>/sendMessage
   DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
   ```

5. **Run the background data updater**:
   In a terminal, start the asynchronous data fetcher:
   ```bash
   python -m src.main --daemon
   ```
   (This will poll RPC every 15 seconds and update internal state.)

6. **Launch the Streamlit dashboard**:
   In another terminal:
   ```bash
   streamlit run src/dashboard/app.py
   ```
   Open `http://localhost:8501` in your browser.

## Validation Scenarios

### Scenario 1: Slippage Analysis
- **Goal**: Verify that the tool can fetch a quote and display route comparison.
- **Steps**:
  1. In the dashboard, navigate to the "Trade" page (or use the CLI command: `python -m src.cli quote SOL USDC 10`).
  2. Enter a token pair and amount (e.g., SOL/USDC, 10 SOL).
  3. Click "Get Quote".
  4. **Expected**: A table appears showing routes with price impact, slippage estimate, and fill probability.
  5. **Pass if**: Table loads within 2 seconds (SC-001) and data is reasonable.

### Scenario 2: LP Position Monitoring
- **Goal**: Verify that a known Orca Whirlpool position is tracked correctly.
- **Steps**:
  1. Add your position ID to the config (or use a test position).
  2. Wait for the background updater to run (15 seconds).
  3. In the dashboard, view the "Positions" page.
  4. **Expected**: Position details (tick range, fees, IL, net yield) are displayed.
  5. **Pass if**: Data updates within 5 seconds of a new RPC response (SC-002).

### Scenario 3: Alert Trigger
- **Goal**: Verify that boundary alerts work.
- **Steps**:
  1. Configure an alert rule in the dashboard for a position (set a threshold for IL or price drop).
  2. Simulate a price movement (or wait for actual price change) that breaches the threshold.
  3. **Expected**: An alert is sent to the configured Telegram/Discord channel within 10 seconds (SC-003).
  4. **Pass if**: Alert is received.

### Scenario 4: Portfolio Risk Metrics
- **Goal**: Verify VaR and Sharpe ratio calculations.
- **Steps**:
  1. Wait for portfolio data to accumulate (at least 30 days of history recommended, but mock data can be used).
  2. Check the "Portfolio" page.
  3. **Expected**: VaR at 95% and Sharpe ratio are displayed numerically.
  4. **Pass if**: Values are consistent with historical data (no obvious errors).

## Troubleshooting

- **RPC rate limit errors**: Increase `polling_interval_sec` or use a paid RPC endpoint.
- **Missing data**: Ensure your config has correct token mint addresses and RPC endpoint.
- **Dashboard not loading**: Check that the background daemon is running and Streamlit is started.

All commands are run from the project root. For full implementation details, refer to the tasks generated by `/speckit-tasks`.
